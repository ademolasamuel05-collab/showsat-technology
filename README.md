# SHOWSAT TECHNOLOGY Website

Responsive multi-page static website.

## Project structure
- `index.html` — Homepage
- `about.html` — About the founder
- `services.html` — Detailed services
- `booking.html` — Quote request and Google Form
- `contact.html` — Contact details, office locations and enquiry form
- `styles.css` — Shared styling
- `script.js` — Mobile navigation and current year
- `assets/` — Logo and image assets

## Preview
Open `index.html` in a browser. No Node.js or build process is needed.

## Publish to your existing GitHub repository
Upload the files and folders from this package into the root of your existing repository. Keep the `assets` folder and filenames unchanged. The project retains the multi-page file layout shown in your GitHub screenshot.

Then go to **Settings → Pages → Deploy from a branch → main → /(root)**.

The CCTV and inverter hero images are illustrative visuals, not photos of completed SHOWSAT jobs. No sample customer reviews are included.

## Mobile layout update
The mobile header has been compacted, contact links are arranged in a tidy two-column layout, the navigation bar is shorter, and the hero content starts closer to the header to remove the excessive blank space.
